# IF Certifica Flow

Crie uma landing page profissional, moderna, responsiva e altamente orientada à conversão para a marca IF Certifica, uma operação de venda e emissão de certificados digitais vinculada à AR TechSign, com a AC Consulti como Autoridade Certificadora.

1. OBJETIVO PRINCIPAL

O objetivo da página é gerar clientes interessados em adquirir ou renovar certificados digitais.

A principal conversão deve acontecer através do WhatsApp, levando o visitante a iniciar uma conversa com um especialista.

15. CONVERSÃO E UX

A página deve ser construída com foco em conversão.

Regras:

CTA de WhatsApp visível no Hero.

Repetir CTA estrategicamente após produtos, benefícios e FAQ.

Em dispositivos móveis, criar um botão de WhatsApp fixo na parte inferior da tela.

Utilizar mensagens pré-preenchidas diferentes para cada produto.

Os cards de produtos devem ser extremamente fáceis de comparar.

Destacar claramente preços.

Não esconder preços.

Não obrigar o usuário a preencher formulário antes de falar com o atendimento.

Priorizar WhatsApp como principal canal de conversão.

Criar excelente experiência mobile.

16. RESPONSIVIDADE

Cards empilhados corretamente.

WhatsApp fixo no mobile.

Boa velocidade de carregamento.

18. DIRETRIZES IMPORTANTES

A página deve transmitir a sensação de:

"É fácil resolver meu certificado digital aqui."

Não transformar a landing page em um site institucional cheio de textos.

Priorizar:

Clareza → Confiança → Produto → Preço → CTA → WhatsApp

A primeira tela deve ser visualmente impactante, mas simples.

Os preços devem ser facilmente encontrados.

Os produtos devem ser facilmente comparados.

O visitante deve entender rapidamente:

O que vocês vendem → quanto custa → qual opção escolher → como entrar em contato.

Não inventar:

depoimentos;

avaliações;

número de clientes;

certificações;

selos;

prêmios;

garantias;

dados da empresa;

diferenciais não fornecidos;

informações regulatórias.

Se alguma informação necessária não estiver disponível, criar um espaço reservado para posterior preenchimento em vez de inventar informação.

RESULTADO ESPERADO

Entregue uma landing page visualmente sofisticada e profissional para a IF Certifica, com aparência de uma empresa moderna de tecnologia e serviços digitais.

O objetivo não é criar apenas um site bonito.

O objetivo é criar uma máquina simples de conversão de visitantes em conversas no WhatsApp e, consequentemente, em vendas de certificados digitais.

Priorize conversão, clareza, confiança, experiência mobile e velocidade.
